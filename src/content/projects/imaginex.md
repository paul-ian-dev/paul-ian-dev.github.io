Imaginex is a personal project: a Pinterest-style app for sharing and discovering images.

- Sign in with Google, then browse a masonry feed of images filtered by category or search.
- Post a pin with an image, title, description, link and category.
- Save other people's pins and comment on them.
- A profile page lists the pins you created and the pins you saved.

The React frontend is styled with Tailwind CSS and hosted on Netlify. Users, pins, comments and images are stored in Sanity, which also provides the content studio.
